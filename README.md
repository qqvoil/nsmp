# NeverSMP Infrastructure & Donation System

Сетевая инфраструктура, донат-платформа и средства управления игровым проектом NeverSMP.

## Структура проекта
- `backend/` — микросервис донатов (Flask/FastAPI, Platega.io API, RCON / MySQL LuckPerms)
- `frontend/` — веб-витрина и магазин для `donate.neversmp.ru`
- `scripts/` — скрипты развертывания, управления серверами и оптимизации на Linux-дедике
- `configs/` — эталонные оптимизированные конфиги Velocity, Paper, LuckPerms, VeloAuth
